# 智能分拣现场采集执行清单

这份清单用于相机和真实物料到位后的第一轮实验。完成一项就记录结果，不要直接进入大批量标注。

## 0. 先固定实验条件

- [ ] 相机临时安装在最终机械臂观察位附近；
- [ ] 托盘位置、相机高度、镜头方向和光源位置记录下来；
- [ ] 物料放置区域完整进入画面，四周保留约 5%～10% 边距；
- [ ] 相机镜头手动调清晰并锁紧；
- [ ] 关闭 Windows 相机、微信、浏览器会议等其他摄像头占用程序。

如果最终机械臂结构尚未完成，先搭一个与最终高度和角度接近的临时支架。正式数据不要在桌面手持相机状态下采集。

## 1. 用 OBS 调曝光和白平衡

在 OBS 中添加“视频采集设备”，选择 `LRCP USB3.0`，第一轮固定为：

```text
1920 × 1080
30 FPS
MJPG（驱动提供时）
```

点击“配置视频”，在“摄像机控制”或“视频处理放大器”中：

- [ ] 关闭自动曝光；
- [ ] 关闭自动白平衡；
- [ ] 关闭自动增益或把增益调到最低；
- [ ] 先用曝光值 -6 作为起点；
- [ ] 放入白色、黑色、红色、蓝色和黄色物料；
- [ ] 白色物料没有整片过曝；
- [ ] 黑色物料仍能看到轮廓和表面；
- [ ] 彩色物料颜色不会随位置变化明显漂移；
- [ ] 快速移动一个物料后，边缘没有明显拖影；
- [ ] 如果太暗，先增加漫射光，再小幅提高曝光，最后才提高增益。

把最终值记录到 `03_系统配置/配置文件/calibration.yaml` 的 `camera` 区域。

## 2. 先验证最终视角，不要马上长时间录像

分别摆放以下场景并截图：

- [ ] 单个物料在托盘中心；
- [ ] 单个物料在四个角落；
- [ ] 多个物料同时出现；
- [ ] 两个物料相邻但不接触；
- [ ] 两个物料贴合；
- [ ] 物料旋转不同角度；
- [ ] 物料靠近托盘边缘；
- [ ] 最高物料和最低物料同时出现。

检查：

- [ ] 最高物料没有被画面边缘裁切；
- [ ] 俯视轮廓足以区分物料类型；
- [ ] 如果两个物料俯视轮廓完全相同，记录为“需要高度表、ToF 或斜视相机验证”；
- [ ] 画面边缘没有严重桶形畸变；
- [ ] 最小物料短边达到约 60 px，最好达到 80～150 px。

只有这一项通过，才进入正式录像。

## 3. 录像

OBS 录像保存到：

```text
01_视频采集与数据集制作/录像/
```

每段录像建议只改变一种因素：位置、角度、颜色组合或遮挡。覆盖中心、边缘、角落、相邻和轻微遮挡。不要让同一个摆放长时间不变。

也可以使用项目程序：

```powershell
.\.venv\Scripts\python.exe `
  ".\01_视频采集与数据集制作\程序\record_camera.py"
```

## 4. 抽帧和数据集检查

```powershell
.\.venv\Scripts\python.exe `
  ".\01_视频采集与数据集制作\程序\extract_dataset_frames.py" `
  --video ".\01_视频采集与数据集制作\录像\录像文件名.avi" `
  --interval 0.5
```

抽帧后检查：

- [ ] 删除手、工具、严重遮挡和异常曝光图片；
- [ ] 删除仍然重复的相邻帧；
- [ ] 每种形状和颜色都有代表性样本；
- [ ] 中心、边缘和角落样本都有；
- [ ] 相邻、贴合和轻微遮挡样本都有；
- [ ] 彩色图和灰度图文件名一一对应；
- [ ] `extraction_report.csv` 中没有大量 `blurred` 或 `near_duplicate` 异常。

## 5. 标注规则

只在：

```text
01_视频采集与数据集制作/输出数据集/color/images/unlabeled/
```

中标注彩色原图。

YOLO 第一版类别只使用形状或物块类型，例如：

```text
circle
square
rectangle
triangle
```

不要把颜色组合成 `red_circle`、`blue_circle` 等大量类别。颜色由彩色原图的传统视觉模块单独判断。

## 6. 训练前验收

- [ ] 所有图片都有对应标签；
- [ ] 没有标签文件引用不存在的图片；
- [ ] 类别编号与 `02_模型训练/配置示例/data.example.yaml` 一致；
- [ ] 按采集批次划分 train、val、test，避免同一段视频的相邻帧同时进入训练和验证；
- [ ] 先训练灰度模型，再保留一份彩色模型作为对照；
- [ ] 记录采集参数、类别顺序、数据集数量和异常图片数量。

验收完成后再把数据集发到游戏本训练，不要在类别顺序和相机参数还会变化时训练最终模型。
