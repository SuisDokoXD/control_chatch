# 视频采集与数据集制作

这是当前项目用于制作 YOLO 训练数据的小工作流。

拿到真实相机和物料后，先按 [现场采集执行清单.md](现场采集执行清单.md) 完成曝光、视角和物料覆盖验证，再开始长时间录像。

## 最终结论

- 使用 OBS 或项目录像程序录制彩色视频。
- 从视频中自动抽取清晰且差异足够大的彩色帧。
- 在彩色原图上使用 AnyLabeling 画框。
- 程序同时生成同名灰度三通道副本，供 YOLO 只学习形状或物块类型。
- 彩色原图和灰度副本共用同一份 YOLO 标签，不需要标注两遍。

## 目录说明

```text
01_视频采集与数据集制作/
├─ 程序/
│  ├─ record_camera.py             摄像头预览和录像
│  ├─ extract_dataset_frames.py    视频抽帧、去模糊、去重复
│  └─ prepare_yolo_input.py        已有彩色图片批量生成灰度副本
├─ 录像/                            默认录像保存位置
├─ 输出数据集/                      默认抽帧结果

```

## 方法一：使用 OBS 录像

在 OBS 中添加“视频采集设备”，选择 `LRCP USB3.0`。第一轮使用：

```text
1920 × 1080
30 FPS
MJPG（驱动允许时）
```

把录像保存到本文件夹的 `录像/` 中。正式采集前固定相机位置、焦点、曝光、白平衡和光源。

## 方法二：使用项目程序录像

在项目根目录打开 PowerShell：

```powershell
.\.venv\Scripts\python.exe ".\01_视频采集与数据集制作\程序\record_camera.py"
```

操作：

- 空格：开始或暂停录像；
- `S`：保存当前彩色照片；
- `Esc`：结束程序。

录像自动保存到 `01_视频采集与数据集制作/录像/`。

## 从视频生成数据集

把命令中的视频文件名替换为实际文件名：

```powershell
.\.venv\Scripts\python.exe ".\01_视频采集与数据集制作\程序\extract_dataset_frames.py" `
  --video ".\01_视频采集与数据集制作\录像\你的录像文件.mp4" `
  --interval 0.5
```

输出：

```text
输出数据集/
├─ color/images/unlabeled/       在这里标注彩色原图
├─ yolo_shape/images/unlabeled/  同名灰度三通道训练副本
└─ extraction_report.csv         抽帧质量报告
```

## 标注原则

只标注 `color/images/unlabeled/` 中的彩色原图。完成后，把同名 `.txt` 标签复制到灰度训练数据集对应的 `labels/` 目录。类别只定义形状或物块类型，不把颜色组合进 YOLO 类别。

## 建议的录制方式

录制时不断改变物块的位置、角度和组合。覆盖托盘中心、边缘、角落、相邻、轻微遮挡和不同颜色。同一摆放不要长时间不动，否则会产生大量重复帧。
